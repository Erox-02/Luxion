## Hardware

- ESP32-S3-WROOM-1U-N16R8
- MPU6500 
- 4× BL5612 H-bridge motor drivers
- TPS63020 3.3V buck-boost
- USB(technically but not really)
- external antenna
- 1S 3.7V 600mAh lipo
- and a lot of caps 
- a diode
- 1x 560k and 100k ohm resistors
